# my-cc-mods

Claude Code の中に住む mod（function hooks で書くプラグイン）を集めた marketplace です。

## Plugins

| 名前 | 内容 |
|---|---|
| agent-office | サブエージェントやチームの動きを、社員が働くオフィスとして pane に描く。`/office` で開く |

## Installation

```
/plugin install <plugin-name> --marketplace saita08/my-cc-mods
```
